# Support

Thanks for using tools from **mcp-tool-shop-org**.

## Where to get help

- **Questions / usage help:** open a **GitHub Discussion** in repos where it's enabled:
  - [InControl-Desktop](https://github.com/mcp-tool-shop-org/InControl-Desktop/discussions)
  - [mcp-voice-soundboard](https://github.com/mcp-tool-shop-org/mcp-voice-soundboard/discussions)
  - [mcp-voice-engine](https://github.com/mcp-tool-shop-org/mcp-voice-engine/discussions)
  - [ThrottleAI-Desktop](https://github.com/mcp-tool-shop-org/ThrottleAI-Desktop/discussions)
- **Bug reports:** open an **Issue** in the relevant repository
- **Security issues:** see [`SECURITY.md`](SECURITY.md)

## Before filing a bug

Please include:

- OS + version
- Runtime (Node/Python/.NET) + version
- Exact command you ran
- Expected vs actual behavior
- Logs / stack traces (redact secrets)

## Response expectations

We aim to respond, but this is an open-source org and response times can vary.
High-quality reports get attention faster.

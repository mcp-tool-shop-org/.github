## What We Build

AI-assisted tools and production pipelines that run on your hardware.
Game engines, ML training workflows, creative instruments, and developer tools —
all local-first, no cloud dependencies, no vendor lock-in.

## Three Lanes

Everything in this org lives in one of three lanes:

- **Shipped** — Production tools with CI, tests, releases, and install commands. Browse them at [mcptoolshop.com](https://mcptoolshop.com).
- **Active Lab** — In-progress work with daily commits. Check the [recent activity](https://github.com/orgs/mcp-tool-shop-org/repositories?q=&type=all&sort=updated).
- **Seed Vault** — Archived prototypes, reusable patterns, and revival candidates. Explore the [prototypes repo](https://github.com/mcp-tool-shop-org/prototypes).

## Principles

| | |
|---|---|
| **Local-first** | Everything runs on your machine. No cloud required. |
| **MCP-native** | Tools compose through MCP. Works with Claude, Cursor, VS Code, any MCP client. |
| **Production-grade** | CI/CD, tests, error handling, security hardening, semantic versioning. |
| **Accessible** | Low-vision-first CLI output. WCAG tooling. Accessibility baked in. |

# .github — MCP Tool Shop Org

Org-level community health files, brand assets, and CI guardrails.

## Key Features

- **Community Health Files** — CODE_OF_CONDUCT, CONTRIBUTING, SECURITY, SUPPORT, LICENSE
- **Org Profile** — The public-facing org README on GitHub
- **Brand Kit** — Palette, OG image manifests, and brand guidelines
- **CI Guardrails** — Automated markdown linting, link checking, and org drift detection
- **Release Docs** — Versioning, maintenance, branch policy, and badge standards

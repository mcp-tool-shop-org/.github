# Maintenance Tiers

Each repo in the org falls into one of three support tiers.

## Tiers

### Active

Actively developed. Bug fixes, features, and security patches.

- CI runs on every qualifying push
- Dependabot PRs are reviewed and merged
- Issues get triaged within a week
- Discussions are monitored

**Repos:** InControl-Desktop, mcp-voice-soundboard, mcp-voice-engine, tool-compass, file-compass, tool-scan, code-batch, backpropagate

### Beta

Feature-complete but stabilizing. Bug fixes and security patches only.

- CI runs but no new features
- Security updates are applied
- Issues are accepted but response times vary

**Repos:** Attestia-Desktop, ConsensusOS, ThrottleAI-Desktop, headless-wheel-builder

### Archived

No longer maintained. Code is preserved for reference.

- CI may be disabled
- Issues are closed with "archived" label
- PRs are not accepted
- README clearly states archived status

**Repos:** (none currently)

## Tier Changes

- Repos move from Active → Beta when focus shifts elsewhere
- Repos move from Beta → Archived after 6 months without meaningful commits
- Archived repos can be revived by opening a Discussion
